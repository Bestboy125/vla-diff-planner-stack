# 第一批目标交互技能（2026-09-12）

后续增加的 Pass、整圈 Rotate、目标旁 Land 及其校准门禁见 [第二批说明](SECOND_BATCH.md)。以下记录第一批验收范围。

实现范围：接近 Approach、远离 Retreat、面对目标 Turn。原有小角度左右旋转、升降入口继续复用，不替换绕飞、扫描或降落控制。尚不包含 Pass、语义降落、组合升降或完整 360° 旋转。

## 操作

机载端沿用原命令；本次安装未启动它，也没有解锁或起飞：

```bash
bash /home/nv/Diff-planner/sh_files/start_onboard_vla_dual_camera.sh \
  --live I_ACCEPT_VLA_AND_OPERATOR_GOAL_PUBLICATION
```

更新的下层启动脚本在 live 模式增加 `/target_interaction` 节点。原相机、定位、规划、全局控制输出门禁保持不变。Windows 前端需要重启后端以加载新接口；页面刷新后进入“板载语义任务”。默认 Dry-run 不下发。

- 接近目标：默认预留间距 1.5 m、人工物体范围余量 0.5 m，实际目标参考点停距为两者之和（2 m）。每段至多 1 m，经原 atomic executor 的 GOTO_WORLD 交由 Diff-Planner；到点后重新检测，近距离只能用精定位结果结束。
- 远离目标：默认 1 m，沿目标指向无人机的水平径向移动，不等同机身正后方。终点固定在 world，分段执行，保持航向、高度。
- 面对目标：保持起始 world 位置，通过已验证的 operator_rotation 位置保持接口连续更新航向。测得航向误差小于约 4°、速度和角速度稳定 0.5 s 后完成；位置漂移超过 0.25 m 则停止。
- 目标：英文单词。全画面最高置信度，或初始左／中／右三分之一区域。不是物体自身坐标系的左右；多目标区域内仍取最高置信度。暂仅适用于静态目标。
- 最大累计移动默认 10 m，上限 15 m。不是保证感知距离；不足时停止并报告，不继续冒进。

第一版没有自动测量物体表面或轮廓。“范围余量”需人工估计；不能据此保证树冠、伸出的枝条等都在安全间距之外。初始目标锁定后，世界坐标变化超过 0.75 m 的候选不会被采用；多个相邻同类物体仍需操作者核对目标。最高置信度选错而无法匹配锁定目标时会超时停止，不偷偷换目标。

## 执行和停止

三个技能都要求新鲜 world 里程计、FCU 已连接已解锁、PX4Ctrl AUTO_HOVER/CMD_CTRL，以及开始时稳定悬停。它们不请求起飞、解锁或切换飞控模式。高度沿用一键启动捕获的地面参考与既有高度边界。

任务请求经 `TARGET_SKILL` 协议由 Bridge 取得现有全局语义互斥；原子运动、其他语义技能及 VLA 跟踪不能并发抢占。状态带 task_id 回传前端，区分接收、执行、停止中和成功／失败／取消。

检测超时、规划失败、目标丢失、超预算、位置漂移都会取消并请求悬停。不跳过目标交互的关键阶段。停止中等待动作取消及实际稳定（或已落地解除解锁）再回传终态；无法确认时保留阻塞，需检查飞机并用遥控器接管，不能把“停止请求发出”当成停止成功。
