# 第二批技能：Pass / 整圈 Rotate / 目标旁 Land

## 状态与安全边界

代码已接入 Windows 地面站和机载独立 `target_interaction` 包，不替换原绕飞技能。没有执行任何实机起飞、解锁或降落。

Pass、整圈 Rotate 使用既有飞行门禁。目标旁 Land 已实现候选点生成、观测体素检查、移向落点、最终复查和原降落控制器交接；**现场传感器标定链和落地观测覆盖尚未验证，自动 Land 的校准门禁保持关闭**。不能把 Dry-run 接口通过理解为允许实飞降落。

含桨外廓按用户确认的 1 m 处理：半径 0.5 m，加 0.3 m 净空，足迹检查半径至少 0.8 m。若“1 m”不是最大含桨水平外廓，应重新确认。当前几何检查保守包含额外体素边界，但不提供动态目标、地面材质、草地、玻璃、水面或细小障碍安全保证。

## 使用

重启更新后的 Windows 后端并刷新页面，在“板载语义任务”中选择：

- **指定侧 Pass**：英文目标、初始画面目标区域、左／右侧、目标预留间距、人工目标范围余量、经过后前进距离、累计移动上限。
- **整圈 Rotate**：顺／逆时针、完整圈数 1–3、参考航向推进速度 10–45°/s（默认 30°/s）。不需要目标检测；实际角速度仍受既有控制器影响。
- **目标旁选点并 Land**：目标、区域、左／右侧和目标间距。机载校准门禁未通过、地面观测不足或下降净空未知时拒绝执行。

机载仍沿用原双相机一键启动命令。不增加解锁或起飞操作。新增参数默认如下，**不要仅为了消除拒绝提示而打开验证开关**：

```text
VLA_LANDING_GEOMETRY_VERIFIED=false
VLA_LANDING_SENSOR_FRAME=（未指定）
VLA_LANDING_CLOUD_TOPIC=/laserMapping/cloud_registered
```

正式启用 Land 前需要验证：该点云确为当前扫描而不是累计地图；点云坐标系及真实雷达测量原点到 world 的带时间戳 TF；地面参考高度；含桨外廓、净空与测量误差；地面覆盖及整段下降空间；板载计算时延。没有任何猜测的 frame 别名或单位矩阵外参补丁。

## 轨迹与完成判据

### Pass

将起点到目标的水平单位向量冻结为 u，world +Z 叉乘 u 为左侧，右侧取反。转头后不改变侧别。目标中心 c、总间距 R = 预留间距 + 人工目标范围余量，指定侧向量 v，出口额外距离 d：

```text
入口 c - R*u + R*v → 侧方 c + R*v → 出口 c + (R+d)*u + R*v
```

上述是 world 锚点，实际分成不超过 1 m 的 GOTO_WORLD 请求，由 Diff-Planner 规划。出发前检查总里程预算；全过程检查与目标间距和距当前段连线的偏差。偏差超过 0.35 m、规划失败等即取消，不偷偷换另一侧。出口到达且运动稳定才完成。只保证按指定侧约束执行或停止，不承诺障碍场景必能通过。

### Rotate

连续累计相邻里程计偏航角的带符号增量，正确跨越 ±π。反向运动扣减进度；不把绝对转角相加。参考航向限速推进，最多领先实测 20°，整圈目标到达且实测累计误差小于约 2.9°、速度和角速度稳定 0.5 s 后成功。位置漂移超过 0.25 m、里程计跳变、反转或超时即停止。

### Land

指定侧生成最多 9 个候选，独立观测地图利用已标定原点到当前 LiDAR 返回点的射线标记可观测自由空间；未知体素不当作自由，近期障碍不被另一条稀疏射线直接清除。每次最多采样 2000 条射线、范围 8 m、体素 0.2 m，因此覆盖不足时会保守拒绝。

每个落点要求足迹内每格有近期明确地面返回点、原始高度散布不超过 4 cm、整体高差不超过 12 cm、拟合坡度不超过 5°、残差不超过 6 cm；下降柱及机体上方余量必须有近期自由空间证据。只能考虑接近初始地面高度的地面，不支持目标顶面或任意高平台降落。

移动期间持续复查目标落点，抵达后稳定并再次复查。通过后只交接一次给原 Bridge：抑制轨迹→确认悬停→单次 LAND→等待 AUTO_LAND／解除解锁反馈。不改原 PX4Ctrl 降落逻辑。飞控解除解锁作为现有完成反馈，不等同额外增加了着陆接触传感器。

进入降落交接前可以取消导航；进入飞控 AUTO_LAND 后，停止按钮不能保证终止下降，必须使用遥控器接管。实现不会在下降过程中恢复规划位置指令抢占飞控。
